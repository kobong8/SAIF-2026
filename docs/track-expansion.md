주소: `#/` → 선택 화면, `#/ai-technology/slide-N` → AI, `#/ax-innovation/slide-N` → AX. 기존 `#slide-N`은 AX로 연결합니다. 같은 HTML/CSS/JS 렌더러가 두 Track을 표시하므로 카드, 상세 설명, 핵심 메시지, 목차, 페이지 이동, 발표 모드와 키보드 조작을 공유합니다.

## 기존 자료 분석과 편집 원칙

AX는 도입 2장과 7명 × 11장으로 구성됩니다. 각 발표는 공식 제목·소속을 사용하는 4개 카드의 상세 요약으로 시작합니다. 이후 개념 → 사례·수치 → 기술적 조건 → 팀 적용 순서로 전개하며, 장마다 카드·상세 설명·Key Takeaway를 둡니다. 수치는 비교 기준과 범위를 설명하고, 팀 적용 예시는 발표 사례와 구분합니다. 마지막 한재준 장표가 검증 가능한 R&D 실행 과제로 마무리합니다.

AI도 같은 정보 구조를 사용하되 원본 근거가 부족한 강연을 장수에 맞춰 늘리지 않았습니다. 강연별 3~5장으로 구성하고 앞뒤 발표의 연결을 상세 설명에 넣었습니다. 강조 문장은 직접 인용이 아니라 편집적 요약입니다. 기존의 진행률 전환, 목차 펼침, 반응형 카드와 발표 모드를 유지했습니다.

## 원본 확인과 사실관계

우선순위는 제공 스크립트, 제공 발표자 요약, 기존 편집 방식, 공식 프로그램 순서입니다. [공식 프로그램](https://saif2026.com/)으로 발표자·소속·제목을 대조했습니다.

- 요약의 `Yoon Kim (윤김)` 대신 실제 자기소개와 공식 프로그램의 **김윤형 · 삼성전자**를 사용합니다. 공통 키노트는 기존 콘텐츠에서 가져옵니다.
- 플랫폼의 공식 세 구성 요소는 **PDE, AI Models, Agent**입니다. Action Framework와 UX·오케스트레이션은 그 아래의 설명으로 정리합니다.
- Kris Hauser는 공식 프로그램의 **삼성전자 RX사업추진실**로 표기합니다. 요약의 대학 소속은 사용하지 않았습니다.
- 황인철(05:11–05:35), 이윤수(05:35–05:55), 이강욱(07:10–07:30)은 한국어 자동 자막이 다수 누락돼 있습니다. 제공 요약과 공식 소개에 근거한 재구성임을 해당 장표에 표시했습니다. 불확실한 구현 세부·수치·직접 인용은 추가하지 않았습니다.
- Metro의 성공률 `32% 개선`은 발표 수치로 표기하며 상대 개선/%p 여부가 자막에 분명하지 않다고 표시합니다. 학습 비용 `최대 56배`도 비교한 계획기와 실험의 범위로 한정합니다.
- 로봇의 `99.99%`는 공장 고객의 기대를 설명한 수치이며 달성 성능이 아닙니다.
- Doc-to-Atom의 지연 절반 이상 감소는 발표 실험에 한정합니다. NB-LoRA를 모든 미래 입력에 대한 `망각 0%` 보장으로 표현하지 않습니다.
- Metro·TrustMe·Doc-to-Atom·NB-LoRA 등의 상세 설명은 사용자 제공 발표 기록의 요약이며, 각 연구의 외부 논문을 독립적으로 재현·검증한 결과는 아닙니다.

## 핵심 narrative와 최종 결론

검증 가능한 업무 위임 → 기기 제약에 맞는 맥락·계산·플랫폼 → 실제 공간에서 결과를 예측하고 행동 → 배포 가능한 신뢰성과 맞춤화 → 경험을 편집·내재화하되 기존 능력을 유지하는 지속 학습.

What We Learned는 ① 제약을 설계의 출발점으로, ② 행동할 공간에서 추론, ③ 성공과 신뢰를 함께 검증, ④ 경험을 보존 가능한 능력으로의 네 메시지입니다.

**Final Takeaway: AI의 다음 도약은 제한된 자원 안에서 현실에 맞게 행동하고, 검증된 경험을 잃지 않으며 계속 배우는 시스템입니다.**

## 랜딩 카드의 요약과 결론

### Keynote + Track 1 · AI Technology

AI 기술은 어디까지 발전하고 있는가?

목표를 수행하는 에이전트에서 출발해, 제한된 기기의 효율과 물리 세계의 행동을 살펴봅니다. 개인의 경험을 기억하고 기존 능력을 보존하며 배우는 기술로 이어집니다.

**종합 결론:** 다음 도약은 효율적인 실행, 현실에서의 검증, 경험을 보존하는 지속 학습을 함께 설계하는 데 있습니다.

### Keynote + Track 2 · AX Innovation

발전한 AI를 실제 산업에 어떻게 적용할 것인가?

개인의 업무 위임을 팀과 기업의 성과로 확장합니다. 사업 목표와 데이터, 안전한 에이전트 운영을 연결하고 반도체 R&D의 탐색·판단·실행 흐름에 적용합니다.

**종합 결론:** 가치 있는 업무를 맡기고 결과를 검증하며, 데이터와 운영 책임을 갖춘 실행 방식을 조직의 자산으로 축적해야 합니다.

- 로컬 검증 결과: `qa/browser-results.json`; 스크린샷과 검증 코드는 Git 제외.

## Git 관리와 배포

테스트 폴더·파일, 캐시, 브라우저 보고서, `qa/`, 원본 TXT, 가상환경은 Git에서 제외됩니다. 빌드 및 실행에 필요한 코드·의존성 목록·실행 스크립트·정적 파일은 계속 관리합니다. 기존 테스트 삭제는 `git rm --cached`를 사용했으므로 로컬 파일은 보존됩니다. 과거 Git 이력은 변경하지 않았습니다.

정적 배포 파일은 이미 재생성했습니다. 검토 후 변경과 테스트 추적 제외를 함께 커밋하고 `develop`을 원격에 푸시하세요. 기존 문서의 Pages 설정이 `main / (root)`이라면 `main`에 병합·푸시하면 됩니다. 새 서버나 라우팅 rewrite 설정은 필요하지 않습니다. 실제 원격 Pages 설정과 공개 배포 결과는 이번 작업에서 변경하거나 확인하지 않았습니다.

## 남은 확인 사항

한국어 강연 세 개의 원본 자막이 불완전하므로 상세 사례나 정확한 수치를 더 넣으려면 해당 영상의 재청취가 필요합니다. 현재 자료는 이를 표시한 보수적 요약입니다. 연구 수치의 일반화나 보편적 보장은 피했습니다. 공개 사이트에는 아직 반영되지 않았습니다.
